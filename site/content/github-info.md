## Recent GitHub updates

- **Nov 18, 2026 - Wait for pull request events with GitHub CLI.** The `gh event listen` preview can wait for reviews, head changes, conflicts, and completed checks instead of polling; it requires `gh` 2.105.0+ and Event Streams access. [GitHub Changelog](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli)
- **Nov 17, 2026 - Maintainers need verified reports, not more AI bug reports.** A GitHub and Microsoft pilot used AI triage and human review to turn thousands of potential findings into 99 private reports with suggested fixes across six projects. [GitHub Blog](https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes/)
- **Daily Issues Report.** Awesome Copilot's weekday workflow summarizes new, closed, and stale issues in a GitHub issue; teams can adapt this pattern for issue triage. [Awesome Copilot](https://github.com/github/awesome-copilot/blob/main/workflows/daily-issues-report.md)
